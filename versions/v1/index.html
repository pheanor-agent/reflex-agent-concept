01From biology to design

지능을 시스템 전체의 적응으로 본다

이 프로젝트에서 지능은 환경의 신호를 받아, 목표에 맞게 행동하고, 결과에 따라 다음 행동을 바꾸는 능력이다. 사고하는 모델뿐 아니라 연결 구조, 짧은 반응 경로, 국소적인 조절 장치까지 설계 대상이 된다.

CONNECTIVITY

연결이 능력을 만든다

초파리 뇌 커넥툼은 신경 연결을 보여준다. 에이전트에서는 이를 입력 신호·판단 모듈·행동 도구가 연결된 그래프로 해석한다. 어느 모델을 쓰는가와 함께, 어떤 경로로 정보가 흐르는가를 설계한다. [1]

LEARNED ROUTINES

반복이 절차를 만든다

반복해서 성공한 행동은 점점 짧은 절차로 처리할 수 있다. 에이전트도 익숙한 판단을 재사용 가능한 정책으로 바꾼다. 처음부터 준비된 기본 경로와 경험으로 익힌 경로가 함께 작동한다. [2]

LOCAL ADAPTATION

작은 단위도 적응한다

단세포 생물 Stentor에서 반복 자극에 대한 습관화가 관찰됐다. 에이전트에서는 재시도 간격·혼잡 조절·중복 억제 같은 국소 제어에 대응시킨다. 의미 판단과 다른 시간척도로 움직인다. [3]

두 가지 적응이 함께 일어난다. 반복 학습은 판단 경로를 짧게 만들고, 국소 제어는 부하와 오류에 맞춰 반응 속도와 처리량을 조절한다. 새로운 문제를 해결하는 능력과 익숙한 문제에 빠르게 대응하는 능력이 함께 성장한다.

02Four levels, one organism

계층을 내릴수록 선택의 폭이 줄어든다

네 계층은 추론 자유도와 적용 범위로 나눈다. 고성능 모델도 실수할 수 있고, 좁은 문제에서는 스크립트가 더 확실하다. 작업 전체뿐 아니라 개별 판단 단계마다 계층을 선택한다.

각 계층이 맡을 일과 남길 산출물
계층맡는 판단출력 / 상위 복귀 조건
L3숙고 계층고성능 범용 모델목표가 모호하거나 기존 정책이 없는 상황. 문제를 분해하고 도구·검증 방법·새로운 전략을 제안한다.계획 + 행동 제안 + 검증 조건정보 부족이나 권한 부족은 질문·보류로 처리한다. 높은 성능도 성공의 증거를 대신하지 않는다.
L2숙련 계층경량 언어 모델익숙한 작업에서 표현 차이와 문맥을 해석한다. 검색된 절차에 인자를 채우거나 알려진 예외를 처리한다.구조화된 인자 + 절차 선택필수 값 누락, 의미 충돌, 검증 실패이면 L3로 넘긴다. 초기에는 예시·검색을 쓰고 필요할 때만 파인튜닝한다.
L1결정 계층Jev식 제한된 정책상태와 선택지가 정해진 문제. 예: 계속 진행·재시도·상위 이관·중단 중 하나를 고른다. 자유로운 계획 생성은 하지 않는다.선택값 + 이유 코드 + 적용 근거규칙·트리·분류기 또는 작은 모델로 구현할 수 있다. 확률적 구현이면 거절·검증 장치가 필요하다.
L0실행 계층스크립트 / 국소 제어입력과 분기가 완전히 정형화된 작업. 검증·해시 비교·규칙 기반 파일 분류·제한된 재시도 등을 수행한다.실행 결과 + 관측 로그계약에 없는 입력은 추측하지 않고 반환한다. 대기시간 등의 조절은 지정된 범위 안에서만 허용한다.

Jev식 결정. 현재 상태, 가능한 행동, 각 행동의 조건을 입력받아 하나의 선택과 이유 코드를 반환한다. 예를 들어 일시적인 도구 오류에는 ‘재시도’, 정보 누락에는 ‘상위 이관’, 예산 초과에는 ‘중단’을 고른다.

03Input · judgment · output · learning

실행은 짧게, 학습은 별도의 루프로

행동 루프는 현재 요청을 해결하고, 학습 루프는 다음 요청의 경로를 개선한다. 새로운 스킬을 만드는 느린 과정이 일상 실행을 매번 막지 않도록 분리한다.

1 / INPUT

신호를 정규화

요청·현재 상태·목표·권한·환경 버전을 구조화한다. 원본의 출처와 신뢰 경계도 함께 보존한다.

2 / JUDGMENT

적합한 경로 선택

이미 검증된 스킬의 적용 조건부터 확인한다. 해당 경로가 없거나 불확실하면 상위 판단을 호출한다.

3 / OUTPUT

행동과 결과 검증

권한을 확인한 실행기가 도구를 호출한다. 관측된 결과를 성공 조건과 대조하고 실패를 기록한다.

4 / LEARNING

경험을 경로로 전환

반복 사례와 실패를 묶고 더 작은 후보를 만든다. 독립 검증 후 스킬의 새 버전을 등록한다.

학습 루프의 검증 결과 → 다음 입력의 라우팅에 반영 · 실행 중 정책을 즉석에서 바꾸지 않음
공통 라우터

빠른 색인 검색과 계약 검사로 시작한다. 모델이 필요할 때만 호출하며, 라우터의 비용과 오판도 측정한다.

공통 실행기

모든 계층이 동일한 권한·예산·도구 계약을 사용한다. 계획과 실제 외부 효과를 구분한다.

공통 경험 저장소

입력·판단 버전·실제 행동·관측 결과·수정 피드백을 연결한다. 모델의 자기평가를 성공 라벨로 쓰지 않는다.

예: 처음 보는 문서를 L3가 해석하더라도 파일 해시 계산·형식 검증·승인된 복사는 L0가 수행할 수 있다. 각 모듈의 연결과 의존성은 스킬 그래프로 표현한다.

05Experience → reusable skill

성공 기록을 ‘실행 가능한 기억’으로

학습 단위는 전체 에이전트가 아니라 조건이 정의된 작은 스킬이다. 경로의 전환은 배포 상태를 바꾸는 일이다. 모델 가중치의 재학습은 여러 선택지 중 하나다.

관측하고 검증한다

입력, 환경, 선택한 계층, 행동, 실제 결과, 실패, 사용자 수정을 에피소드로 저장한다. 성공은 파일의 위치·내용 해시·독립 라벨처럼 관측 가능한 기준으로 판정한다.

상태: 기록됨 · 실패 사례도 남겨 성공 편향을 줄인다.

반복의 공통 조건을 찾는다

유사한 입력과 행동을 묶어 무엇이 고정되고 무엇이 변하는지 분리한다. 입력 표면이 비슷해도 목표·권한·환경이 다르면 별도의 작업군으로 다룬다.

상태: 후보 · 예외와 반례를 함께 포함한다.

더 좁은 표현으로 바꾼다

L3의 절차를 L2용 예시·템플릿으로, L2의 반복 선택을 L1 정책으로, 고정된 분기를 L0 코드로 표현한다. 상위 모델의 설명을 그대로 실행하지 않고 입력·출력 계약을 작성한다.

전환은 선택적이다. 명확한 알고리즘이 있으면 L3 → L0로 건너뛸 수 있다. 자유로운 문맥 판단은 L2에 남을 수 있다.

독립 평가와 그림자 실행을 거친다

학습에 쓰지 않은 시간대·작업군의 데이터와 반례를 평가한다. 기존 결과를 재생한 뒤, 실제 입력에서 후보 결과만 비교하는 그림자 실행을 한다. 생성한 모델과 별개의 검증기가 평가한다.

상태: 검증 중 · 상위 모델과의 일치율은 보조 지표다. 실제 정답·행동 결과가 우선이다.

범위를 제한해 적용하고 복귀를 준비한다

작은 비율의 허용된 작업에서 시작해 품질과 비용을 본다. 버전을 고정하고 표본 감사를 유지한다. 계약 위반·품질 하락·환경 변경은 스킬을 격리하고 기존 버전 또는 상위 계층으로 돌린다.

상태: 제한 적용 → 활성 → 격리 / 재검증 · 처음부터 제공되는 검증된 기본 스킬도 공존한다.

06A single task, growing expertise

“이 문서들을 알맞게 정리해줘”

처음에는 분류 기준부터 해석해야 한다. 다음에는 문서의 의미만 해석하면 된다. 표준 입력이 자리 잡으면 제한된 결정으로, 고정 규칙이 확정되면 코드로 처리할 수 있다.

새 목표 / L3

기준을 발견

문서 샘플에서 분류 기준을 제안한다. 모호한 경우 사용자가 정답을 확정한다. 검증 가능한 파일 복사 계획을 만든다.

새 기준 → 계획
익숙한 문맥 / L2

의미를 해석

저장된 예시로 다양한 제목과 본문을 분류한다. 필수 정보가 없거나 두 폴더가 경쟁하면 상위 판단을 요청한다.

문맥 → 구조화된 인자
표준 메타데이터 / L1

제한된 선택

문서 유형·발행처·분류 코드로 허용 폴더를 고른다. 알 수 없는 코드에는 ‘상위 이관’을 반환한다.

상태 → 고정된 선택지
완전한 계약 / L0

규칙을 실행

명확한 매핑 테이블로 경로를 결정한다. 파일 해시·중복·복사 결과를 검증하고 원본을 보존한다.

조건 → 검증된 실행
FAST PATH

익숙한 서식은 바로 처리

발행처 A의 정형 문서가 검증된 매핑과 일치하면 L0로 간다. 문서 B는 의미 해석이 필요하므로 L2를 쓴다. 에이전트 전체를 하나의 계층으로 고정하지 않는다.

LOCAL CONTROL

작은 조절은 늘 함께 작동

동일 이벤트 중복 억제, 제한된 지수 백오프, 큐 혼잡 시 처리율 조절은 L0에서 계속 동작한다. 조절 범위와 중단 조건은 미리 정하며, 의미 판단 정책을 바꾸지 않는다.

‘생각을 생략한다’의 정확한 의미. 이미 명시된 조건에서는 추론을 생략하되 입력 계약·권한·결과 검사는 수행한다. 익숙한 반응에도 관측과 중단 능력이 남는다.

07Applicability before confidence

빠른 경로에는 복귀 조건이 필요하다

‘자신 있다’는 말로 자동화를 허용하지 않는다. 적용 범위와 독립 검증 근거를 확인하고, 애매하면 거절하거나 상위 계층으로 이관한다.

품질 제약을 만족하는 경로 중 총비용이 가장 작은 것을 선택한다.총비용 = 판단 + 라우팅 + 실행 + 감사 + 학습비용 상각 + 실패의 기대 손실선택 조건 = 입력 계약 충족 ∧ 권한 충족 ∧ 평가된 오류 위험 ≤ 작업별 허용치 ∧ 예산 충족
낯선 입력을 익숙한 것으로 착각하면?

필수 필드·스키마·환경 버전을 먼저 검사한다. 의미 유사도 하나만으로 발동하지 않는다. 확률적 분류기는 독립 데이터에서 보정된 점수와 거절 임계값을 쓰고, 경계 사례와 실제 실패율을 지속적으로 확인한다. 드문 작업군은 별도 성능을 본다.

몇 번 성공하면 코드로 내려도 될까?

보편적인 횟수는 없다. 성공 사례의 다양성, 반례 커버리지, 오류율의 신뢰구간, 실패 영향과 예상 재사용량으로 결정한다. 드물거나 고위험인 작업은 끝까지 상위 계층에 남을 수 있다. 단순 반복 횟수를 안정성의 증거로 쓰지 않는다.

잘못된 습관이 굳어지면?

표본 감사·환경 지문·계약 위반 신호로 변화를 탐지한다. 실패 스킬을 격리하고 관련 스킬의 의존성을 확인한다. 관측 오류와 판단 오류, 도구 오류를 구분해 수정하며, 이전 버전을 보존한 채 재검증한다.

계속 상위 모델로 올려도 해결되지 않으면?

에피소드당 호출·시간·재시도 예산을 둔다. 같은 실패의 반복은 자동 중단한다. 정보나 권한이 없으면 사용자에게 필요한 부분만 요청한다. 상위 계층도 실패할 수 있으므로 ‘가장 큰 모델까지 갔음’을 완료 판정으로 쓰지 않는다.

입력 문서가 에이전트를 속이려 하면?

문서의 내용은 데이터로 처리하고, 그 안의 지시로 도구 권한·정책·정답 라벨을 바꾸지 않는다. 학습 후보는 격리된 환경에서 검증한다. 외부 행동을 유발하는 후보는 실행 전에 공통 권한 검사를 통과해야 한다.

숙련도와 실행 권한은 독립적이다. 전송·삭제·결제처럼 별도 권한이 필요한 행동은 반복 성공으로 권한을 얻지 않는다. 사용자 승인이나 사전에 위임된 정확한 범위가 있어야 실행한다.

08Project brief / REFLEX

작은 작업군에서 가설을 검증한다

첫 프로젝트는 로컬 테스트 문서의 분류와 복사로 제한한다. 원본을 보존하고 실험용 작업 공간에서 실행한다. 목표는 동일한 품질을 유지하며 반복 작업의 총비용을 낮추는지 확인하는 것이다.

MINIMUM SYSTEM

첫 버전의 구성 요소

  • 입력 어댑터 + 스킬 색인: 입력 계약과 환경 버전을 확인한다.
  • 네 계층의 처리기: L3/L2는 교체 가능한 모델 어댑터, L1은 제한된 정책, L0는 실행 코드.
  • 공통 실행기 + 검증기: 권한·예산·사후 조건을 확인한다.
  • 경험 원장 + 후보 생성기: 사례를 저장하고 오프라인에서 후보를 만든다.

초기 저장소는 SQLite 또는 JSONL과 버전 관리된 스킬 파일이면 충분하다. 모델 공급자와 실제 모델은 실험 조건을 정할 때 선택한다.

TESTABLE HYPOTHESIS

검증할 질문

  • 같은 품질 기준에서 총비용·응답 시간이 감소하는가?
  • 새로운 작업군과 서식 변경을 알아차리고 이관하는가?
  • 잘못 분류한 사례를 학습해 반복 오류를 줄이는가?
  • 직접 만든 규칙보다 학습한 경로가 충분히 나은가?

초기 범위: 한 작업군, 제한된 도구, 오프라인 평가. 자율적인 운영 시스템 변경과 범용적인 자기 개선은 후속 연구 과제다.

Phase A / Observe

기준 성능 확보

L3가 판단하고 L0가 실행한다. 분류 라벨·행동 결과를 확보하고 성공·실패의 기록 계약을 정한다.

완료 조건: 시간·작업군으로 분리한 평가 세트와 반복 가능한 기준 실험.

Phase B / Specialize

작은 경로를 비교

L2 템플릿, L1 분류 정책, L0 규칙을 후보로 만든다. 고정 라우팅과 적응 라우팅을 같은 요청에서 비교한다.

완료 조건: 사전 정의한 품질 하한과 총비용 기준을 만족하는 좁은 후보.

Phase C / Adapt

변화와 복귀 검증

새 서식·잘못된 메타데이터·환경 버전 변경을 주입한다. 후보 격리, 상위 이관, 이전 버전 복귀를 검증한다.

완료 조건: 예외 탐지·복구·예산 준수의 재현 가능한 시나리오.

비교 실험과 지표

① 항상 L3로 판단 ② 사람이 작성한 고정 규칙/고정 라우터 ③ 학습과 전환을 포함한 REFLEX를 동일 조건에서 비교한다. 후보를 만드는 기록과 평가 기록은 분리하고, 파일 내용 해시·실제 목적지·독립 정답으로 결과를 판정한다.

결과 품질 / 작업군별 오류

정답 분류율, 실제 행동의 성공률, 잘못된 폴더 복사율. 드문 유형과 예외를 별도로 집계한다.

총비용 / 지연

모델 호출·라우팅·실행·검증·학습·복구를 모두 포함한다. 평균과 p95 지연을 함께 본다.

자동 처리 범위 / 잘못된 확신

전체 요청 중 낮은 계층에서 정확히 처리한 비율, 계약 밖 입력의 오수용률, 불필요한 상위 이관율.

변화 대응 / 손익분기

환경 변경 탐지와 복귀까지의 시간, 검증 비용을 회수하는 데 필요한 반복 횟수. 반복이 적으면 경로 생성이 손해일 수 있다.

이 프로젝트의 중심 자산은
경험으로 자라는 ‘행동 경로의 지도’다.

어떤 입력을, 어떤 조건에서, 어느 모듈이, 어떤 행동으로 바꾸는지 기록한다. 검증된 연결은 짧아지고, 새로운 경험은 연결 가능한 범위를 넓힌다.

09Evidence & adjacent ideas

설계를 뒷받침하는 연구

신경 연결 연구는 모듈 사이의 정보 흐름을, 세포 적응 연구는 국소적인 반응 조절을 생각하게 한다. 지식 증류와 모델 라우팅은 경험을 더 작은 처리 경로로 옮기는 기술로 연결된다.

  1. [1] Neuronal wiring diagram of an adult brain

    Dorkenwald et al., Nature, 2024. 성체 암컷 초파리 뇌의 139,255개 뉴런과 약 5,450만 시냅스를 재구성했다. 감각 입력부터 출력까지의 연결을 추적할 수 있어, 에이전트의 모듈과 행동 경로를 설계하는 출발점이 된다.

  2. [2] A critique of pure learning and what artificial neural networks can learn from animal brains

    Zador, Nature Communications, 2019. 선천적 회로와 학습 기반 행동의 관계에 대한 관점 논문. REFLEX에서도 검증된 기본 스킬을 초기부터 제공하고 학습 경로와 함께 사용한다.

  3. [3] Single-cell analysis of habituation in Stentor coeruleus

    Rajan et al., Current Biology, 2023 (온라인 공개 2022). 반복 기계 자극에 대한 단세포의 반응 변화와 강한 자극에 대한 반응을 연구했다. 국소 단위에서도 자극 이력에 따라 반응이 바뀌는 사례다.

  4. [4] Distilling the Knowledge in a Neural Network

    Hinton, Vinyals & Dean, 2015. 큰 모델의 지식을 작은 모델로 전달하는 증류 연구. L3에서 학습한 동작을 L2의 처리 능력으로 옮길 때 활용할 수 있다.

  5. [5] FrugalGPT: How to Use Large Language Models While Reducing Cost and Improving Performance

    Chen, Zaharia & Zou, 2023. 여러 언어 모델을 비용과 품질에 맞게 조합하는 관련 연구. REFLEX의 계층 선택, 비용·품질 평가, 상위 이관 경로를 설계할 때 참고할 수 있다.
