# REFLEX v2 구현 로드맵

첫 실험은 로컬 테스트 문서를 분류하고 복사하는 작업이다. 원본을 보존하고, 독립적인 정답과 실제 파일 결과로 품질을 평가한다. 반복 학습이 품질을 유지하면서 총비용과 지연을 줄이는지 확인한다.

## 1단계 기준 성능

L3가 분류를 판단하고 L0가 파일 작업을 수행한다. 입력과 행동의 계약, 경험 저장 형식, 독립 검증기를 먼저 구현한다.

완료 조건:

- 시간과 작업군으로 분리한 학습·평가 문서가 있다.
- 분류 정답, 실제 목적지, 파일 내용 해시를 검증할 수 있다.
- 같은 입력과 버전에서 기준 실험을 반복할 수 있다.
- 성공·실패·보류, 비용, 지연이 경험 원장에 연결된다.

## 2단계 처리 경로 전문화

반복 사례에서 L2 템플릿, L1 결정 정책, L0 규칙을 후보로 만든다. 과거 입력 재생과 그림자 실행으로 후보를 비교하고, 적용 가능한 작업군을 정한다.

완료 조건:

- 후보별 입력 조건과 거절 조건이 명시되어 있다.
- 학습에 사용하지 않은 데이터와 반례에서 평가를 수행한다.
- 사전에 정한 작업군별 품질 하한을 만족한다.
- 라우팅·감사·학습 비용까지 포함한 손익을 비교한다.

## 3단계 변화와 복귀

새 서식, 잘못된 메타데이터, 환경 버전 변경, 도구 실패를 주입한다. 후보 격리와 상위 이관, 이전 버전 복귀를 연결한다.

완료 조건:

- 계약 밖 입력이 거절 또는 상위 이관된다.
- 검증 실패에 따른 격리와 재검증이 작동한다.
- 재시도·호출·시간 예산이 지켜진다.
- 기존 권한 밖 행동은 보류된다.
- 변화 탐지부터 정상 처리 복귀까지의 시간을 측정한다.

## 비교 실험

같은 평가 입력에서 세 방식을 비교한다.

| 방식 | 확인할 점 |
| --- | --- |
| 항상 L3로 판단 | 고성능 모델 경로의 기준 품질과 비용 |
| 사람이 작성한 고정 규칙·라우터 | 수동 전문화의 품질·적용 범위·유지 비용 |
| 경험으로 경로를 전환하는 REFLEX | 학습과 전환을 포함한 전체 손익·변화 대응 |

핵심 지표는 작업군별 오류율, 행동 성공률, 총비용, 평균·p95 지연, 낮은 계층의 정확한 처리 비율, 계약 밖 입력의 오수용률, 불필요한 상위 이관율, 변화 대응 시간이다.

품질 하한과 예산은 실제 작업군의 실패 영향에 맞춰 실험 전에 정한다. 반복 횟수와 후보 생성 비용으로 손익분기를 계산해 전문화할 작업을 선택한다.


## 4단계 도메인별 격리와 조건부 협업

문서 분류·이미지 영수증 판독·일정 추출을 세 영역으로 나눈다. 모든 영역은 공통 권한·실행·독립 검증 경로를 유지한다. 사진 영수증 분류와 문서의 납기일 추출을 복합 작업으로 추가한다.

완료 조건:

- 서로 다른 지식 저장소와 검색 범위를 실제 접근 계층에서 집행한다.
- 모든 영역 간 호출은 필드·출처·발동 조건·예산을 검증하는 중개기를 통과한다.
- 한 영역의 오류와 무관한 규칙이 다른 영역에 전파되는 정도를 측정한다.
- 단일 작업에서는 무관한 영역이 활성화되지 않고 복합 작업에서는 필요한 연결이 열린다.
- 함수·스킬 모듈과 독립 서브에이전트의 조율 비용을 비교한다.

## 5단계 구조 후보의 진화

모델과 스킬 버전을 고정한 상태에서 그래프 및 지식 접근 범위를 변형한다. 부모 계보·변형 연산·평가 근거를 보존하고, 작업군별로 다양한 구조를 보관한다. 구조 탐색을 검증한 다음에 스킬 학습과 결합한다.

완료 조건:

- 분할·통합·연결 추가·삭제·조건화 후보가 스키마와 권한 검사에 통과한다.
- 후보 생성·선별·최종 테스트의 데이터가 분리되어 있다.
- 새 하위 목표 조합, 희귀 작업, 환경 변경을 별도로 평가한다.
- 작업군별 품질 하한을 통과한 후보에서 총비용·지연·간섭·적응력을 비교한다.
- 구조 탐색·유지·복구 비용까지 포함한 손익분기를 계산한다.
- 제한 적용 후 실패 주입에서 구조·스킬·지식 버전 묶음이 일관되게 복귀한다.

## 구조 비교 실험

| 구조 | 비교 목적 |
| --- | --- |
| 전부 공유 | 통합 능력과 무관한 컨텍스트·통신의 비용 |
| 고정 격리 | 단일 작업 효율과 복합 목표의 단절 |
| 사람이 설계한 조건부 연결 | 정적 전문화와 명시적 통합 경로 |
| 평가를 거쳐 진화하는 구조 | 새 환경 적응과 탐색 비용을 포함한 전체 손익 |

첫 비교에서는 동일한 모델·스킬·도구·예산·정답을 사용한다. 다음에는 구조 고정/진화 × 스킬 고정/학습의 2×2 실험을 수행해 두 적응 축의 개별 효과와 결합 효과를 확인한다. 검색·검증·실행의 공통 기반 비용도 모든 방식에 포함한다.

환경은 고정 목표, 하위 목표가 재조합되는 환경, 기존 분해 방식으로 해결하기 어려운 새 목표의 세 종류로 나눈다. 새로운 목표에서 품질이 하락하면 기존 분해를 유지한 채 연결만 줄이는 대신 모듈 경계와 역할 자체를 다시 탐색한다.

핵심 지표는 단일/복합/희귀 작업 성공률, 작업군별 최악 품질, 무관한 정보 접근량, 메시지·토큰 사용량, 실패 전파, 총비용, 구조 복귀 시간, 구조 탐색 비용 회수 기간이다.
